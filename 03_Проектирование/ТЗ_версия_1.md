# Техническое задание, версия 1

**Тема:** №6 «Мероприятия». **Проект:** ОРБИТА — платформа поиска, организации и регистрации на мероприятия.
**Студент:** Сидоров Егор Денисович, группа 4ИСИП-723. **Практика:** УП.09.01, ПМ.09.

## 1. Назначение и проблема

Сведения о мероприятиях разбросаны по афишам и чатам, а запись ведут в таблицах: легко записать больше людей, чем есть мест, или внести одного человека дважды. Платформа собирает мероприятия в один каталог, принимает регистрации и гарантирует, что лимит участников не будет превышен.

**Границы проекта.** Входит: каталог, карточка, регистрация и отмена, кабинет участника, панель организатора, роли, статистика обращений. Не входит: онлайн-оплата, листы ожидания, рассылка писем, загрузка файлов, мобильное приложение.

## 2. Пользователи и роли

| Роль | Возможности |
|---|---|
| Гость | просмотр каталога, карточек, категорий; регистрация аккаунта; форма контактов |
| Участник (user) | запись на мероприятия и отмена, кабинет, история посещений |
| Организатор (organizer) | всё, что у участника, + создание и правка своих мероприятий, список участников, отметка присутствия, отмена регистраций своих мероприятий |
| Администратор (admin) | управление любыми мероприятиями, статистика обращений, сообщения из формы контактов |

## 3. Предметное правило

Число активных регистраций на мероприятие не превышает его лимит участников; один пользователь не может иметь две активные регистрации на одно мероприятие; отмена освобождает место. Проверка выполняется на сервере (транзакция) и в БД (триггеры и уникальный индекс).

## 4. Функциональные требования и критерии приёмки

| Код | Требуемое действие | Критерий приёмки |
|---|---|---|
| ФТ-01 | Каталог: карточки, поиск по названию, фильтр по категории и датам, сортировка, постраничный вывод (9 на странице) | Результат соответствует запросу; условия сохраняются при переходе между страницами; пустой результат объяснён |
| ФТ-02 | Страница мероприятия: дата, место, описание, организатор, занято/свободно/лимит | Данные читаются из БД; несуществующий номер даёт 404 |
| ФТ-03 | Регистрация и отмена с лимитом участников | Активных регистраций не больше лимита, в том числе при 30 одновременных запросах; повтор отклоняется; отмена освобождает место; пользователь видит понятное уведомление |
| ФТ-04 | Регистрация аккаунта, вход, выход, роли | Пароль хранится хешем; логин уникален; после выхода защищённые действия недоступны |
| ФТ-05 | Личный кабинет: предстоящие, история посещений, отменённые, отмена | Видны только собственные регистрации; чужую отменить нельзя (403) |
| ФТ-06 | Панель организатора: создание, правка, удаление, публикация, список участников, свободные места | Недопустимые данные отклоняются с сохранением введённого; организатор управляет только своими событиями |
| ФТ-07 | Защита данных | CSRF-токены, экранирование вывода, параметризованные запросы, права проверяются на сервере |
| ФТ-08 | Информационные страницы, SEO, журнал обращений | title/description/canonical, sitemap.xml, robots.txt; статистика обращений для администратора |

## 5. Сценарии

| № | Исходное состояние | Действия | Результат |
|---|---|---|---|
| С1 | Участник вошёл; на мероприятии осталось одно место | Нажимает «Зарегистрироваться» | Регистрация создана, сообщение «осталось: 0»; следующему пользователю кнопка недоступна |
| С2 | Организатор вошёл | Создаёт мероприятие с лимитом 3, публикует; три участника записываются | В панели «занято 3, свободно 0»; четвёртая регистрация отклонена; отмена одной освобождает место |
| С3 | Участник знает адрес чужой регистрации | Отправляет запрос отмены напрямую, без кнопок | Ответ 403, регистрация осталась активной |

## 6. Данные и ограничения

Сущности: categories, events, registrations (+ учётные записи users и служебные sessions, messages, access_log). Подробно — `02_Данные/Схема_БД.md`.

## 7. Интерфейс

Тёмный минималистичный стиль по референсу (чёрное поле, тонкая сетка, один акцентный цвет), адаптивность 360 / 768 / 1280 px, видимый фокус, подписи полей, состояния: пустой список, ошибка ввода, нет записи (404), нет прав (403).

## 8. Среда и запуск

Node.js 24, SQLite (встроена). Команды запуска — `01_Проект/README.md`.
