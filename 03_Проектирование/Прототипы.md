# Прототипы экранов

Схемы составлены до вёрстки; итоговые экраны — в `04_Проверки/снимки_экрана`. Обязательные поля отмечены «*».

## П1. Список (каталог)

```
[ОРБИТА]  Каталог  Категории  О платформе  Контакты        [Войти] [Регистрация]
КАТАЛОГ
Все мероприятия
┌ Название ________ Категория ▾  Дата с __  Дата по __  Сортировка ▾ ┐
│ (Предстоящие|Прошедшие|Все)  ☐ Со свободными местами  ☐ Бесплатные  [Применить][Сбросить] │
└──────────────────────────────────────────────────────────────────────┘
Найдено: 48 · страница 1 из 6
┌────────┐ ┌────────┐ ┌────────┐      карточка: фото · дата · категория · город
│ фото   │ │ фото   │ │ фото   │      название · день недели, время · место
│ название│ │        │ │        │      [▬▬▬░░ 11 мест из 30]  цена
└────────┘ └────────┘ └────────┘
← Назад   1  2  3 … 6   Далее →            (условия фильтра сохраняются в ссылках)
```
Состояния: **пустой список** — «Ничего не найдено» + «Сбросить фильтры»; заполненное событие — метка «Мест нет».

## П2. Карточка мероприятия

```
Главная / Каталог / Категория
КАТЕГОРИЯ · [метка состояния]            ┌ фото ┐
Название мероприятия                      └──────┘
Краткое описание
┌ дата и время │ место │ организатор ┐   ┌ РЕГИСТРАЦИЯ ─────────┐
О мероприятии                          │ Цена  ▬▬▬░░ 11 из 30   │
  описание, программа (список)         │ занято | свободно | лимит │
Похожие события                        │ [Зарегистрироваться]  │
                                       └───────────────────────┘
```
Кнопка по состояниям: гость → «Войти и зарегистрироваться»; свободно → «Зарегистрироваться»; записан → «Вы зарегистрированы» + «Отменить регистрацию»; нет мест → «Мест нет» (неактивна); прошло/отменено → неактивна. **Нет записи** — страница 404.

## П3. Форма мероприятия (создание и редактирование)

```
Название*  Категория*  Формат*
Краткое описание* (10–200)
Подробное описание
Город*  Место*  Начало*  Окончание*  Лимит участников*  Стоимость  Публикация
[Создать мероприятие] / [Сохранить изменения]  [Отмена]
```
Ошибка ввода: поле подсвечивается, под ним — причина, введённые значения сохраняются. При редактировании лимит нельзя сделать меньше числа занятых мест. Внизу при редактировании: опубликовать / снять / отменить / удалить.

## П4. Вход

```
Вход                      ┌ Логин* ______ ┐
С возвращением            │ Пароль* ______ │
• кабинет • регистрация   │ [Войти]  Нет аккаунта? Зарегистрируйтесь │
```
Ошибка: «Неверный логин или пароль» (одинаково для неизвестного логина и неверного пароля), 401.

## П5. Кабинет и «Мои регистрации»

```
Мои регистрации
(Предстоящие 3) (История посещений 5) (Отменённые 1)
┌ [14 ноя] КАТЕГОРИЯ · Город
│ Название  дата · место · цена          [Подробнее] [Отменить]
```
Пустые состояния для каждой вкладки.

## П6. Панель организатора

```
Ваши мероприятия
Всего | Активных | Регистраций | Заполненность
[+ Создать мероприятие]
Мероприятие | Дата | Статус | Места 12/30 ▬▬░ свободно 18 | [Участники][Изменить]
```
Страница «Участники»: лимит, занято, свободно, статус; таблица (имя, e-mail, дата записи, статус, «Отметить», «Отменить»), CSV.

## Взаимная проверка сценария

Сценарий С1 пройден вдвоём с одногруппником: ____ (запись заполняется студентом после фактической проверки; в материалах проверка с одногруппником не выполнялась автоматически).
