# УП.09.01 — «ОРБИТА» (вариант 6 «Мероприятия»)

Студент: Сидоров Егор Денисович, группа 4ИСИП-723. Платформа поиска и регистрации на мероприятия; правило темы: число активных регистраций не превышает лимит участников.

Запуск: `cd 01_Проект` → `npm run db:reset` → `npm start` → http://localhost:3000 (Node.js ≥ 22.13, зависимости не нужны). Логины и подробности — `01_Проект/README.md`.

| Папка | Содержимое |
|---|---|
| 01_Проект | исходники, README, тесты, замеры, резервное копирование |
| 02_Данные | схема БД, миграции, ER-диаграмма, резервная копия |
| 03_Проектирование | ТЗ, карта страниц и матрица доступа, прототипы |
| 04_Проверки | протокол из 60 тестов, журнал дефектов, чек-лист безопасности, 47 снимков экрана |
| 05_Измерения | протокол измерений, журнал 43 обращений, замеры до/после |
| 06_SEO_Продвижение | SEO-проверка, макет анонса |
| 07_Документы | отчёт (docx, pdf), дневник, протокол восстановления, матрица соответствия, личный план |
| tools | вспомогательные скрипты (съёмка экранов, сборка отчёта); зависимости ставятся `npm install` |

Не выполнено (см. `07_Документы/Матрица_соответствия.md`): публикация анонса, проверка с другого рабочего места, запуск другим студентом; даты и подписи в дневнике вносит студент.
